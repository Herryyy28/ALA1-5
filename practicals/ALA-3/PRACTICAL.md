## 1. Research Aim & Objectives
* Evaluate the Shared Responsibility Model across IaaS, PaaS, and SaaS service models.
* Analyze Identity and Access Management (IAM), RBAC, ABAC, and the Principle of Least Privilege.
* Investigate cryptographic key management and Envelope Encryption (AES-256-GCM + KMS).
* Benchmark security services across AWS, Azure, and Google Cloud.
* Conduct root-cause analyses on real-world cloud security breaches (Capital One, Uber).

## 2. Platform Comparison Matrix
* **AWS:** IAM, KMS (CloudHSM Level 3), CloudTrail, GuardDuty, Shield Advanced.
* **Microsoft Azure:** Microsoft Entra ID, Azure Key Vault, Azure Monitor, Defender for Cloud.
* **Google Cloud:** Cloud IAM, Cloud KMS, Cloud Audit Logs, Security Command Center.
