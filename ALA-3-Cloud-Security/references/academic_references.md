## 1. Official Standards & Government Regulatory Frameworks
1. **NIST SP 800-145:** Mell, P., & Grance, T. (2011). *The NIST Definition of Cloud Computing*. National Institute of Standards and Technology, U.S. Department of Commerce. [https://doi.org/10.6028/NIST.SP.800-145](https://doi.org/10.6028/NIST.SP.800-145)
2. **NIST SP 800-53 Rev. 5:** National Institute of Standards and Technology. (2020). *Security and Privacy Controls for Information Systems and Organizations*. U.S. Department of Commerce.
3. **NIST SP 800-207:** Rose, S., Borchert, O., Mitchell, R., & Connelly, S. (2020). *Zero Trust Architecture*. NIST Special Publication 800-207.
4. **ISO/IEC 27017:2015:** International Organization for Standardization. *Information technology — Security techniques — Code of practice for information security controls based on ISO/IEC 27002 for cloud services*.
5. **ISO/IEC 27018:2019:** International Organization for Standardization. *Code of practice for protection of personally identifiable information (PII) in public clouds acting as PII processors*.

## 2. Cloud Service Provider Security Whitepapers & Architecture Guides
6. **Amazon Web Services (AWS):**
   - *AWS Well-Architected Framework: Security Pillar* (Whitepaper, 2024 update). AWS Documentation: [https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/)
   - *AWS Key Management Service Cryptographic Details* (Whitepaper). Amazon Web Services, Inc.
   - *AWS Identity and Access Management (IAM) Best Practices* (2025). AWS Reference Architecture.

7. **Microsoft Azure:**
   - *Azure Security Benchmark (v3)*. Microsoft Corporation, Redmond, WA. [https://learn.microsoft.com/en-us/security/benchmark/azure/](https://learn.microsoft.com/en-us/security/benchmark/azure/)
   - *Azure Key Vault Developer's Guide & Cryptographic Specifications*. Microsoft Learn.
   - *Microsoft Entra ID (formerly Azure Active Directory) Zero Trust Deployment Guide*.

8. **Google Cloud Platform (GCP):**
   - *Google Infrastructure Security Design Overview*. Google Cloud Documentation. [https://cloud.google.com/security/infrastructure/design](https://cloud.google.com/security/infrastructure/design)
   - *Encryption at Rest in Google Cloud*. Google Security Whitepaper.
   - *BeyondProd: A new approach to cloud-native security*. Google Cloud Architecture Center.
